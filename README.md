# Movie Night

ორი აპი MyKadri-ის ქართული ფილმებისა და სერიალებისთვის:

- **Mac:** ლოკალური აპი, რომელიც Chromecast / Google Cast-ით აგზავნის ვიდეოს ტელევიზორში.
- **Android TV:** დამოუკიდებელი აპი Sony Bravia-სთვის — კატალოგი, ძებნა და ყურება პულტით, Mac-ის გარეშე.

## Mac-ზე გაშვება

ორჯერ დააჭირე **[Start Kadri TV.command](<Start Kadri TV.command>)**. აპი გაიხსნება Chrome-ში: **http://localhost:8765**.

1. Mac და ტელევიზორი ერთ Wi-Fi ან ლოკალურ ქსელში შეაერთე.
2. დააჭირე „ტელევიზორის არჩევა“. თუ TV არ გამოჩნდა, განაახლე სია ან მიუთითე მისი IP მისამართი.
3. ჩასვი MyKadri-ის ბმული ან აირჩიე ფილმი კატალოგიდან.
4. აირჩიე სერია და დააჭირე „ტელევიზორში გაშვება“.

ქვემოთ გამოჩნდება პაუზა, გაგრძელება, გადახვევა და ხმის მართვა. Mac-ის აპის გაშვებისას Terminal-ის ფანჯარა ღია დატოვე; სერვერის გასაჩერებლად დააჭირე `Ctrl+C`.

თუ macOS ადგილობრივ ქსელზე წვდომას გთხოვს, დაუშვი, რათა აპმა TV იპოვოს. TV-ზე Google Cast / Chromecast built-in ჩართული უნდა იყოს. IP მისამართს იპოვი ტელევიზორის ქსელის პარამეტრებში.

საჭიროა Python **3.11 ან ახალი** და ინტერნეტი. ამ Mac-ზე გარემო უკვე მომზადებულია; სხვა Mac-ზე პირველი გაშვება საჭირო პაკეტებს ჩამოტვირთავს.

## Sony Bravia / Android TV-ზე დაყენება

მიმდინარე ვერსია: **1.0.7 — Movie Night**. ყურება ხდება მხოლოდ Movie Night-ის ჩვეულებრივ ფლეერში. 1.0.6-ში დამატებული გარე ფლეერები და მათზე გადასასვლელი ღილაკები ამოღებულია. თუ გვერდზე პირდაპირი HLS/MP4 ნაკადი არ არის, აპი შესაბამის შეტყობინებას აჩვენებს. „მე ვარ გრუტის“ ამ ბმულზე ხელმისაწვდომია მხოლოდ გარე ფლეერები; პირდაპირი დაკვრა ამჟამად მიუწვდომელია.

**1.0.5-ის ცვლილება:** აპის ახალი სახელი ჩანს TV-ის აპების სიაში, აპის ზედა პანელში და სისტემური მთავარი ეკრანის ფილმების რიგზე. ამ რიგში პირველია ბოლოს გახსნილი ფილმები, ახალიდან ძველისკენ; დარჩენილი ადგილები შემთხვევით შერჩეული ფილმებით ივსება. ისტორია და ყურების დრო განახლებისას შენარჩუნებულია.

**1.0.4-ის ცვლილება:** ხარისხის მენიუ აჩვენებს ვიდეოში რეალურად არსებულ ვარიანტებს — არჩევა შეგიძლია ფილმის გახსნამდეც და ფლეერშიც. დაემატა TV-ის მთავარი ეკრანის ფილმების ბარათები; ბარათი შესაბამის ფილმს აპში ხსნის.

**1.0.3-ის ცვლილება:** ზედა პანელში პირდაპირი ძებნის ველია; „ბოლოს ნანახი“ ბარათები მთავარ კატალოგს ზემოთ გამოჩნდება. წინა ვერსიის ისტორია შენარჩუნებულია.

**1.0.2-ის ცვლილება:** დაემატა ცარიელი HLS მონაკვეთების ამოცნობა და ხანგრძლივი ჩატვირთვიდან აღდგენა. სტანდარტული ავტომატური რეჟიმი 1080p-მდეა.

**1.0.1-ის ცვლილება:** დაემატა MyKadri-ის `justfile.store` ვიდეოსერვერისა და `movie` ფლეერის კონფიგურაციის მხარდაჭერა — მათ შორის „გალაქტიკის მცველებისთვის“. გამოსწორება დაფარულია ახალი რეგრესიული ტესტებით ორივე აპში (სულ 22 ტესტი). ემულატორში ამ ფილმზე „ყურების“ ღილაკი გამოჩნდა და ვიდეო PLAYING მდგომარეობაში გადავიდა. თუ წინა ვერსია უკვე დაყენებულია, ახალი APK გახსენი და აირჩიე განახლება; ძველი აპის წაშლა საჭირო არ არის.

დასაინსტალირებელი ფაილი: **[MovieNight-1.0.7.apk](releases/MovieNight-1.0.7.apk)** — Android 6.0 ან ახალი, ARM-ის ორივე ვარიანტი მხარდაჭერილია.

1. გადაიტანე APK USB მეხსიერებაზე და შეაერთე ტელევიზორში.
2. TV-ის ფაილების მენეჯერში გახსენი APK. თუ დაყენების ნებართვას მოგთხოვს, დაუშვი ამ ფაილების მენეჯერიდან აპის დაყენება.
3. დაყენების შემდეგ გახსენი **Movie Night** აპების სიიდან.

TV-ის პროგრამისა და მოდელის მიხედვით პარამეტრების სახელები შეიძლება განსხვავდებოდეს. თუ ფაილების მენეჯერი არ გაქვს, APK გადაიტანე შენთვის ხელმისაწვდომი ფაილების გადაცემის საშუალებით.

პულტის ისრებით ირჩევ ფილმს; `OK` ხსნის დეტალებსა და სერიებს. ზედა პანელის ძებნის ველში ჩაწერე ფილმის სახელი ან სრული MyKadri ბმული და დააჭირე კლავიატურის ძებნას / Enter-ს. მთავარ გვერდზე „ბოლოს ნანახი“ ბარათები აჩვენებს შენახულ ისტორიას; ისრებით შეგიძლია მათი ჰორიზონტალურად დათვალიერება და გახსნა. ისტორიის ცარიელ მდგომარეობაში ეს რიგი დამალულია. ფლეერს აქვს პაუზა, გადახვევა, შემდეგი სერია და ფლეერის სტანდარტული კონტროლები. აპი ინახავს ყურების ადგილს და ბოლოს გახსნილ ფილმებს.

პირდაპირ ვიდეოფლეერში მომდევნო სერია იმავე სეზონისა და ენის ფარგლებში ავტომატურად ჩაირთვება. `Back` მალავს ფლეერის კონტროლებს; განმეორებით დაჭერა აბრუნებს სერიების სიაში. `Home`-ზე გადასვლისას ვიდეო ჩერდება და ყურების დრო ინახება.

### ვიდეოს ხელმისაწვდომობა

„ყურება“ ჩანს მხოლოდ მაშინ, როცა გვერდიდან Movie Night-ის ფლეერისთვის პირდაპირი ვიდეონაკადი ამოიკითხება. თუ გვერდზე მხოლოდ გარე ფლეერებია, გამოჩნდება შეტყობინება: „ამ გვერდზე მხოლოდ გარე ფლეერებია. Movie Night-ის ფლეერისთვის პირდაპირი ვიდეონაკადი ვერ მოიძებნა.“ გარე ფლეერის ჩატვირთვა, მისი სკრიპტების გაშვება და სხვა ფლეერში გადამისამართება აღარ ხდება.

სერიები, ხარისხის არჩევა, გადახვევა და პოზიციის შენახვა ისევ Movie Night-ის ფლეერში მუშაობს პირდაპირი ნაკადების მქონე ფილმებზე. Mac-ის Chromecast აპიც პირდაპირ ვიდეონაკადებს იყენებს.

### ფილმები TV-ის მთავარ ეკრანზე

Android TV 8.0-დან აპი ამატებს **Movie Night** რიგს, მაქსიმუმ 12 ბარათით. დასაწყისში ჩანს ბოლოს გახსნილი ფილმები, ახალიდან ძველისკენ; შემდეგ — MyKadri-ის მთავარი კატალოგიდან შემთხვევით შერჩეული ფილმები, გამეორების გარეშე. ბარათზე `OK` პირდაპირ შესაბამისი ფილმის გვერდს ხსნის აპში.

ბოლოს გახსნილი ფილმების რიგი ყოველი გახსნის შემდეგ ახლდება, ქსელის მოთხოვნისა და ექვსსაათიანი განრიგის ლოდინის გარეშე. შემთხვევითი ფილმების სია ინტერნეტის არსებობისას დაახლოებით ყოველ 6 საათში ახლდება; დროის სიზუსტეს TV-ის ფონური დავალებების განრიგი განსაზღვრავს. ფილმის გახსნისას დარჩენილი შემთხვევითი ბარათები თავიდან არ ირევა. Mac-ის ჩართვა საჭირო არ არის.

რიგის ჩვენებასა და მდებარეობას TV-ის მთავარი ეკრანი მართავს. ამ Sony Bravia-ზე რიგი ავტომატურად გამოჩნდა. TV-ის პარამეტრებიდან დამალული რიგი ან მომხმარებლის მიერ წაშლილი ბარათი აპს ხელახლა იძულებით არ გამოაქვს.

ეს არის პირადი დაყენებისთვის ხელმოწერილი **debug APK**, Play Store-ზე გამოქვეყნების გარეშე. მომავალი განახლების იმავე ხელმოწერით ასაწყობად შეინახე ლოკალური `.android-home/debug.keystore`.

## მხარდაჭერა და შემოწმება

მითითებული **VisionQuest** გვერდიდან ექვსი ქართული სერია ამოიკითხა; რეალური HLS ფლეილისტები ჩაიტვირთა. შესრულდა Python-ისა და Android-ის პარსერის ტესტები, Mac-ის ბრაუზერის ძირითადი მოქმედებებისა და ეკრანის ზომების შემოწმება. Android-ის ემულატორში აპი გაიხსნა, პულტის ნავიგაცია შემოწმდა და რეალური HLS ვიდეო დაიკრა. განახლებები ამ Mac-იდან ფიზიკურ Sony Bravia-ზეც დაყენდა. ## ბუფერი და ხარისხი

ფლეერი ვიდეოს ნაწილს წინასწარ ტვირთავს ([სტანდარტული სამიზნე დაახლოებით 50 წამია](https://raw.githubusercontent.com/androidx/media/1.9.4/libraries/exoplayer/src/main/java/androidx/media3/exoplayer/DefaultLoadControl.java); რეალურად მზადყოფნა ქსელის სიჩქარესა და მეხსიერებაზეა დამოკიდებული). შორს გადახვევისას ახალი მონაკვეთის ჩამოტვირთვა სჭირდება. ბუფერის გაზრდა სერვერზე ცარიელ ან დაზიანებულ ვიდეომონაკვეთს ვერ აღადგენს.

„გალაქტიკის მცველების“ დაახლოებით 60-ე წუთზე შემოწმებისას 1440p ვერსიის რამდენიმე მონაკვეთი HTTP 200 პასუხით, მაგრამ 0 ბაიტით მოდიოდა. იმავე ადგილას 720p და 1080p იტვირთებოდა. ამიტომ სტანდარტული ავტომატური რეჟიმი ახლა 1080p-მდეა. ცარიელი HLS მონაკვეთები შეცდომად აღიქმება, რათა ფლეერს სხვა ხელმისაწვდომ ხარისხზე გადასვლა შეეძლოს.

ფილმის გვერდზე „ყურების“ ზემოთ აირჩიე „ხარისხი“. დაკვრისას პულტით გამოაჩინე კონტროლები და აირჩიე ზედა მარჯვენა „ხარისხი“ ღილაკი; `MENU` ღილაკიც ხსნის ამ მენიუს, თუ პულტი ამ კლავიშს აპს გადასცემს. სია ვიდეოში არსებულ რეზოლუციებს აჩვენებს; ფლეერში დამატებით გათვალისწინებულია TV-ის მხარდაჭერა. მაგალითად, „გალაქტიკის მცველებზე“ წყაროს აქვს 720p, 1080p და 1440p, მიუხედავად საიტზე მითითებული 720p წარწერისა.

კონკრეტული რეზოლუციის არჩევა შესაბამის ვიდეონაკადს აფიქსირებს; „ავტომატური · 1080p-მდე“ ხარისხს კავშირის მიხედვით ცვლის. არჩევანი შემდეგ ფილმებზეც ინახება. თუ არჩეული რეზოლუცია შემდეგ ვიდეოზე არ არის, ფლეერი ავტომატურ რეჟიმს იყენებს. შეცვლისას ყურების ადგილი შენარჩუნებულია. ხელით არჩეულ ხარისხზე ცარიელი მონაკვეთის აღმოჩენისას ფლეერი ავტომატურ რეჟიმში ერთხელ ხელახლა ცდის. რეალური არჩევანი დამოკიდებულია წყაროში არსებულ ვარიანტებზე — აპი ახალ ხარისხებს არ ქმნის.

თუ აქტიური ჩატვირთვა დაახლოებით 20 წამზე მეტხანს გაგრძელდა, გამოჩნდება „720p-ით ცდა“, „ხელახლა“ და „უკან“. ხელახლა ცდა ინარჩუნებს ფილმსა და გადახვევის ადგილს. ჩატვირთვისას ეკრანზე ჩანს, რამდენი წამია უკვე მზად. სერვერის მიუწვდომლობისას უწყვეტი ჩვენება გარანტირებული ვერ იქნება.

## კოდი და ხელახლა აწყობა

`mac/` — Python / Flask და PyChromecast; `android-tv/` — Java და AndroidX Media3; `tests/` — პარსერისა და API-ის ტესტები.

```sh
.venv/bin/python -m unittest discover -s tests -v
./scripts/build-tv.sh
```

Android-ის ასაწყობად საჭიროა Android SDK 36, JDK 17 ან ახალი და ინტერნეტი. Android Studio-შიც იხსნება `android-tv/` საქაღალდე. აწყობის სკრიპტი caches-ს სამუშაო საქაღალდეში ინახავს.

ტექნიკური ცნობები: [Google Cast](https://developers.google.com/cast/docs/overview), [PyChromecast](https://github.com/home-assistant-libs/pychromecast), [Android TV](https://developer.android.com/training/tv/get-started/create), [Media3](https://developer.android.com/media/media3/exoplayer/hello-world).
